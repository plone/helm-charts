To access {{ ternary "the frontend" "the site" .Values.frontend.enabled }} without routing, run:
{{- if .Values.frontend.enabled }}

  kubectl port-forward --namespace {{ .Release.Namespace }} service/{{ include "plone.fullname" . }}-frontend 3000:{{ .Values.frontend.service.port }}

and open http://localhost:3000.
{{- else }}

  kubectl port-forward --namespace {{ .Release.Namespace }} service/{{ include "plone.fullname" . }}-backend 8080:{{ .Values.backend.service.port }}

and open http://localhost:8080/{{ .Values.site.id }}.
{{- end }}

The plone-backend image comes with an "admin" user with the password "admin".
Change it before exposing the site, see https://github.com/plone/helm-charts#admin-user.
