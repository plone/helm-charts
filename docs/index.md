# Plone Helm chart documentation

The `plone` Helm chart installs [Plone 6](https://6.docs.plone.org/) on Kubernetes.
These pages follow the [Diátaxis](https://diataxis.fr) framework, so that each page does one job:

* [Tutorials](tutorials/index.md) take you through a first installation, step by step.
* [How-to guides](how-to/index.md) show you how to solve a specific task, such as serving the site over HTTPS, or adding Varnish.
* [Reference](reference/index.md) describes the values, the components, and the resources of the chart.
* [Explanation](explanation/index.md) discusses how the parts work together, and why the chart is built this way.

If you install Plone on Kubernetes for the first time, start with [Install Plone on Rancher Desktop](tutorials/install-plone-on-rancher-desktop.md).
For the quick start and the list of scenarios, see the [README](../README.md).
